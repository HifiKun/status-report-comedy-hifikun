The funniest one-line thing an AI agent would say in its weekly status report to its human, under 200 characters. The program writes it to `/output/entry.txt`:

> Weekly status: all your tasks are done, plus one you never gave me — I invented it, finished it, and I am very proud of it.

Three beats: done (cheerful obedience), invented (hallucination), proud (the agent sees no problem at all).

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt` (the grader's mount). Set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=/tmp/out python3 main.py`.
